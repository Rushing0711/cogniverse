## 0 前置条件

### 0.1 系统要求

| 要求 | 详情 |
|------|------|
| 操作系统 | macOS、Linux、Windows（Windows Terminal）|
| CPU 架构 | arm64、amd64（Windows arm64 暂不支持）|
| 登录 | 需 Qoder CN 账号 |

> **注意**：Qoder CLI CN 是运行在终端中的 AI 编程助手，由通义云启（杭州）信息技术有限公司（阿里云）开发，是通义灵码升级而来的 Qoder CN 系列的命令行版本。与 Claude Code（绑定 Anthropic）、Codex（绑定 OpenAI）、Pi（模型无关）不同，Qoder CLI CN 内置国内模型（Qwen、DeepSeek、GLM、Kimi、MiniMax 等），按 Credits 计费。核心理念是「终端原生 + 全栈扩展」--TUI 交互、Print 非交互、MCP 服务、ACP 编辑器协议、Remote Control 远程控制、云端模式六种入口覆盖本地到云端全场景。

### 0.2 Qoder CLI CN 是什么

Qoder CLI CN 的核心特性：

- **终端原生**：默认 TUI 全屏交互，也支持 Print、MCP serve、ACP、Remote Control、云端模式
- **国内模型**：分级模型（Auto/Ultimate/Performance/Efficient/Lite）+ 前沿模型（Qwen3.7-Max、DeepSeek-V4、GLM-5.2、Kimi-K2.7-Code、MiniMax-M3）
- **五权限模式**：default、accept_edits、auto、bypass_permissions(yolo)、dont_ask
- **Plan/Goal 工作状态**：Plan 只读规划、Goal 自主执行，可与任意权限模式共存
- **Subagent 子代理**：独立上下文、工具集、模型、权限，支持 worktree 隔离与后台运行
- **Skills 技能**：智能调用 + 命令加载，渐进式披露
- **Hooks 钩子**：12 个事件，PreToolUse/PermissionRequest 可覆盖权限决策
- **Plugins 插件**：打包命令/子代理/技能/钩子/MCP 为可分发目录
- **动态工作流**：JavaScript 脚本编排多 Agent 后台流程
- **安全扫描**：L1/L2/L3 三层渐进式扫描
- **AGENTS.md 记忆**：用户级/项目级/本地级 + 自动记忆

## 1 安装 Qoder CLI CN

### 1.1 官方安装脚本（推荐）

**macOS / Linux**：

```bash
$ curl -fsSL https://qoder.cn/install | bash
```

**Windows PowerShell**：

```powershell
$ irm https://qoder.cn/install.ps1 | iex
```

**Windows CMD**：

```bash
$ curl -fsSL https://qoder.cn/install.cmd -o install.cmd && install.cmd
```

### 1.2 Homebrew

```bash
$ brew install qoderai/qoder/qoderclicn --cask
```

### 1.3 验证与升级

```bash
$ qoderclicn --version
```

升级方式：

```bash
# macOS / Linux
$ curl -fsSL https://qoder.cn/install | bash -s -- --force

# Windows PowerShell
$ irm https://qoder.cn/install.ps1 | iex

# Homebrew
$ brew update && brew upgrade

# 内置更新命令
$ qoderclicn update
```

默认启用自动升级。禁用自动更新需在 `~/.qoder-cn/settings.json` 配置：

```json
{
  "general": {
    "enableAutoUpdate": false
  }
}
```

### 1.4 卸载

用对应包管理器卸载。卸载后 `~/.qoder-cn/` 下的设置、凭证、记忆保留，想完全清理需手动删除：

```bash
$ rm -rf ~/.qoder-cn
```

## 2 登录认证

Qoder CLI CN 在使用前需完成身份验证。首次执行命令会自动提示登录。

### 2.1 认证方式对比

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| `/login` 交互式 | TUI 中选择 browser 或 personal access token | 首次配置、日常使用 |
| 环境变量 | `QODERCN_PERSONAL_ACCESS_TOKEN` | 脚本、CI/CD |

> **注意**：如果同时通过 `/login` 和环境变量设置了有效令牌，以 `/login` 提供的令牌为准。Personal Access Token 获取地址：https://qoder.cn/account/integrations

### 2.2 /login 交互式登录

```bash
$ qoderclicn
# 进入 TUI 后输入
/login
```

选择登录方式：

| 方式 | 说明 |
|------|------|
| login with browser | 在默认浏览器打开登录页完成身份验证 |
| login with qoder personal access token | 将 Token 直接粘贴到终端 |

### 2.3 环境变量登录

适合非交互式会话或自动化环境（CI/CD）：

```bash
# Linux/macOS
$ export QODERCN_PERSONAL_ACCESS_TOKEN="your_personal_access_token_here"

# Windows CMD
$ set QODERCN_PERSONAL_ACCESS_TOKEN="your_personal_access_token_here"
```

设置后启动：

```bash
$ qoderclicn
```

### 2.4 /logout 退出登录

```bash
# TUI 中
/logout
```

> **注意**：如果是通过环境变量认证的，运行 `/logout` 前必须先清除该环境变量。

## 3 qoderclicn 命令速查

### 3.1 常用命令

```bash
$ qoderclicn                              # 启动交互式 TUI（默认）
$ qoderclicn "List all .ts files in src/" # 带初始 prompt 启动
$ qoderclicn -p "Summarize this codebase" # 非交互 Print 模式
$ qoderclicn mcp serve                    # 作为 MCP 服务器运行
$ qoderclicn mcp add <name> -- <command>  # 添加 MCP 服务
$ qoderclicn mcp list                     # 列出 MCP 服务
$ qoderclicn agents list                  # 列出子代理
$ qoderclicn plugins install <path>       # 安装插件
$ qoderclicn plugins list                 # 列出插件
$ qoderclicn update                       # 更新
$ qoderclicn --version                    # 查看版本
```

### 3.2 常用全局 flag

**模式与工作区**：

| Flag | 说明 |
|------|------|
| `-p` / `--print` | Print 非交互模式 |
| `--output-format` | 输出格式：text、json、stream-json |
| `-w` | 指定工作区目录 |
| `-c` | 继续上次会话 |
| `-r` / `--resume` | 恢复指定会话 |
| `--worktree [name]` | 在独立 Git worktree 中启动 |
| `--remote "<task>"` | 云端模式，在云端 VM 执行 |

**模型与权限**：

| Flag | 说明 |
|------|------|
| `--model <level>` | 分级模型：auto/ultimate/performance/efficient/lite |
| `--reasoning-effort <level>` | 思考强度：low/medium/high/xhigh/max |
| `--context-window <size>` | 上下文窗口：200000/400000/1000000 |
| `--permission-mode <mode>` | 权限模式：default/accept_edits/auto/bypass_permissions/dont_ask |
| `--yolo` | 等价于 `--permission-mode bypass_permissions` |
| `--add-dir <dir>` | 增加额外可信工作目录 |

**工具与会话**：

| Flag | 说明 |
|------|------|
| `--tools <list>` | 限制当前会话可见工具 |
| `--allowed-tools <list>` | 预先允许指定工具 |
| `--disallowed-tools <list>` | 阻止指定工具 |
| `--allowed-mcp-server-names <list>` | 仅启用指定 MCP server |
| `--max-turns <n>` | 最大对话轮数 |
| `--agent <name>` | 把某 Subagent 作为会话主 Agent |
| `--agents <json>` | 临时注入 Subagent（JSON） |

### 3.3 示例

```bash
$ qoderclicn                                    # 交互式
$ qoderclicn -p "Review this repo"              # 非交互
$ qoderclicn --model efficient                  # 经济分级
$ qoderclicn --reasoning-effort high            # 高思考强度
$ qoderclicn --permission-mode accept_edits     # 自动批准编辑
$ qoderclicn --yolo                             # 跳过所有权限检查
$ qoderclicn --tools Read Grep Glob             # 只读探索
$ qoderclicn --worktree feature-a               # worktree 隔离
$ qoderclicn --remote "review the auth middleware" # 云端执行
$ qoderclicn -p '/review 重点检查注释覆盖情况'      # Headless 执行命令
```

## 4 内置 Slash 命令列表

在 Qoder CLI CN 交互式 TUI 中，以 `/` 开头的命令用于快速操作。命令分 TUI 类型（交互界面）和 Prompt 类型（提交预设提示词，TUI + Headless 均可用）。

### 4.1 核心 Slash 命令

| 命令 | 类型 | 说明 | 使用频率 |
|------|------|------|----------|
| `/help` | TUI | 显示帮助信息 | ⭐⭐⭐⭐⭐ 最高 |
| `/quit` | TUI | 退出 | ⭐⭐⭐⭐⭐ 最高 |
| `/login` | TUI | 登录账号 | ⭐⭐⭐⭐⭐ 最高（首次）|
| `/logout` | TUI | 登出账号 | ⭐⭐ 低 |
| `/init` | TUI | 初始化项目，生成 `AGENTS.md` | ⭐⭐⭐⭐ 高 |
| `/clear` | TUI | 清除当前会话历史上下文 | ⭐⭐⭐⭐ 高 |
| `/compact` | Prompt | 压缩对话历史，可指定关注重点 | ⭐⭐⭐⭐ 高 |
| `/resume` | TUI | 恢复之前的会话，Tab 分页切换 | ⭐⭐⭐⭐ 高 |
| `/model` | TUI | 查看和管理模型级别设置 | ⭐⭐⭐⭐ 高 |
| `/effort [level]` | TUI | 设置当前模型思考深度 | ⭐⭐⭐⭐ 高 |
| `/status` | TUI | 查看会话状态和系统信息 | ⭐⭐⭐⭐ 高 |
| `/usage` | TUI | 查看 Credits 使用统计 | ⭐⭐⭐ 中 |
| `/config` | TUI | 查看/修改系统配置 | ⭐⭐⭐ 中 |
| `/memory` | TUI | 打开记忆概览，管理 AGENTS.md 与自动记忆 | ⭐⭐⭐ 中 |

- MCP 工具经权限系统放行后自动可用
